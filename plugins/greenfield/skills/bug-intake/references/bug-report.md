# Bug report

```
# Bug: {title}
Severity:
Environment:
First seen:

## Repro
1. numbered steps, from a clean state

## Expected
## Actual

## Evidence
Logs, screenshots, failing test names, request ids. Quote, do not summarize.

## Likely locus
Files or systems, each with a confidence: high, medium, low.

## Hypotheses
Ranked. None chosen.

## Gone when
The observable definition of fixed. This becomes the done-when check.

Route: direct-to-implementer | options-first | cannot-reproduce
Not doing here: fix, refactor, plan
```

When the route is `direct-to-implementer`, add the lines an implementer needs so the report can serve as a single work package:

```
Files allowed:
Constraints:
Ask first:
Escalate if:   the cause turns out to be outside the files above, or the fix needs a design choice
```
