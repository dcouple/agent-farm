# README visual style

The approved direction is **Pixel farm**, selected from three banner concepts.
The canonical visual reference is [agent-farm-banner.png](agent-farm-banner.png).
Use this theme for all future README illustrations.

## Art direction

- Crisp pixel art with a consistent pixel scale, clear silhouettes, and an isometric farm setting.
- Midnight charcoal backgrounds; warm cream lettering; moss and mint greens with muted gold and lilac accents.
- Cozy nighttime lighting from lanterns and terminal screens. Playful, carefully crafted indie-game atmosphere.
- Terminal-shaped huts, tidy skill crop plots, code-symbol sprouts, connecting paths, and the small cream robot farmer with a straw hat.
- Generous negative space and a clear focal point. Keep details legible at typical GitHub README width.
- Use chunky pixel lettering sparingly. Keep explanations, commands, and technical labels in accessible Markdown.

Avoid photorealism, smooth 3D renders, painterly blur, serif poster typography,
bright neon, third-party logos, or fabricated product screenshots.
Real terminal screenshots and technical diagrams should remain accurate and readable;
do not redraw their contents as decorative pixel art.

## Creating another image

Inspect and supply the approved banner as a style reference to the image-generation
tool. Preserve its palette, pixel treatment, lighting, and character design while
changing the scene to suit the section. A text prompt alone is not the reference.
Save the generated asset and its final prompt in this directory, and check it
alongside the banner at README display size before using it.

Reusable prompt opening:

> Create a README illustration for Agent Farm matching the supplied approved
> pixel-farm banner. Treat it as a style reference: preserve its crisp pixel art,
> midnight charcoal background, warm cream, moss/mint green, muted gold and lilac
> palette, cozy lantern lighting, isometric farm world, and robot character design
> when present. Adapt the scene to: [section subject]. Keep the composition simple
> and readable at GitHub README width. No text unless explicitly requested, no
> third-party logos, no watermark, no fake product UI.

The banner's generation prompt is recorded in [banner-prompt.md](banner-prompt.md).
